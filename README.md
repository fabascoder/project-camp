# Controle de Temperatura de Alimentos

Projeto desenvolvido com React Native e Expo para o controle da temperatura dos alimentos servidos em escolas.

## Instalação

Clone o repositório:

```bash
git clone https://github.com/fabascoder/project-camp.git
```

Acesse a pasta do projeto:

```bash
cd nome-do-projeto
```

Instale as dependências:

```bash
npm install
```

## Dependências

Instale as bibliotecas utilizadas no projeto:

```bash
npm install @react-navigation/native
npm install @react-navigation/native-stack
npx expo install react-native-screens react-native-safe-area-context
npx expo install @react-native-picker/picker
```

## Executando o projeto

Para iniciar o projeto, execute:

```bash
npm run web
```

Ou, caso prefira utilizar o Expo:

```bash
npx expo start
```
